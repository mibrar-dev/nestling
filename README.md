# Nestling

Family chores & pocket money app for the UK — parents set quests, children earn coins and grow Pip the chick. Flutter (iOS + Android).

- `app/` — Flutter app (feature-first, BLoC, go_router, get_it). See `docs/ARCHITECTURE.md`.
- `design/` — approved screens (light/dark), store screenshots, asset pack, HTML source.
- `docs/` — design spec, spacing spec, tech stack, setup checklist, pricing & marketing, animation guides.
- `tools/` — Rive/Lottie generators, simulator screenshot harness.

Domain: getnestling.co.uk · Bundle id: uk.co.getnestling.app
