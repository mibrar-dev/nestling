## 3. Rulings

**(a) Do Kanka/World Anvil kill paid mobile TTRPG?** No kill, but cap. Verified free-good-enough + self-host + Notion/Obsidian. No native mobile with GB traction is opportunity *and* warning: ceiling £3-6k yr1 minus LLM cost. Not fatal, but un-investable for money goal.

**(b) Correct chore listing strategy?** **NOT Kids Category, NOT 17+. Ship as 4+/9+ parent productivity, parent-account-only, 13+ target on Play, no ad SDKs.** Apple 1.3 requires parental gate + no third-party analytics/ads in Kids Category; 2.3.8: “For Kids/For Children” reserved for Kids Category, “Apps not in Kids Category cannot include terms…imply main audience is children” ([guidelines](https://developer.apple.com/app-store/review/guidelines)). Use “family habit-building for parents.” Apple ratings now 4+/9+/13+/16+/18+ ([Apple Jul 2025](https://developer.apple.com/news?id=ks775ehf)). Real cost: +2-3wks DPIA + gate + dual profiles + listing re-test — accept Bunny’s ~40%.

**(c) Does BGG clause + BG Stats kill #3?** Yes for money goal. XML API “prohibit…commercial purposes…case-by-case” ([commercial](https://boardgamegeek.com/wiki/page/BGG_XML_API_Commercial_Use)), registration+token required ([using API](https://boardgamegeek.com/using_the_xml_api)). Can ship without sync, but BG Stats £4.99 one-off proves UK won’t pay sub. One-time £6.99 = £5k net max. Unviable.

**(d) Is pocket-money resistance fatal?** No. 27.4% regular + ad-hoc top-ups *growing*, parents paying more per chore. Resistance is to paying for basic duties, not to reward-ledger. Position as ad-hoc rewards + ledger-only (no FCA), not salary-for-dishes.
