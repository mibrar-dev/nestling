## 3. Rulings

**(a) Does Board Game Stats kill #3? Yes, as a business.** Still safest to ship, still £0 marginal cost. Dead on arrival for year-1 income: ~£1.6k on 15k downloads at 2.5% Pro. Don’t build for rent.
**(b) Avoid Kids Category but still ICO-bound? Yes.** Tactic holds: list as parent productivity 4+, no Kids tick, parental gate on paywall/payout/settings, zero ads, zero third-party SDKs. But Children’s Code applies if *likely to be accessed by children* regardless of targeting — DPIA, high-privacy defaults, minimisation, no nudges, export/delete. Real cost: **4-6 weeks part-time** + 1-2 review rejections, not 0.5.
**(c) TTRPG middle path? No.** DM-only payer (4-6 free-ride), pause/churn kills £34.99/yr, AI £0.70-1.80/active/mo eats margin, alias/dedup + one hallucinated NPC kills trust. 90 subs = hobby.
